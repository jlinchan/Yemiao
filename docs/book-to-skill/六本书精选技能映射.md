# 夜喵「书中技能 · 精选」内容映射

> 运行时数据源：`data/book-skills.js`。本文件记录技能选择依据、来源定位和核验边界；书名、短简介、长简介和排序由 `data/book-directory.js` 统一维护。

## 1. 数据关系

```text
Book
  ├─ shortDescription   首页与全部列表，最多 14 个字符
  ├─ introduction       书籍介绍页长简介
  └─ Skill[]
       ├─ id / bookId
       ├─ 名称 / 简介 / 图标
       ├─ concept / scenario / questions / exercise
       ├─ prompt
       └─ source / verification
```

对话入口统一传递 `bookId`，精选技能另外传递 `skillId`。`services/book-context.js` 根据两个 ID 读取技能数据并组装 AI 系统上下文，页面不通过查询字符串携带大段知识正文。

## 3. 安全边界

- CBT-I 技能只做睡眠教育、记录和概念解释，不向用户制定或调整睡眠限制处方。
- 所有书籍技能都不用于诊断、贴病名或替代专业咨询。
- 《也许你该找个人聊聊》和《非暴力沟通》尚未直读中文版原文，因此没有虚构章节、页码、原话或具体案例。
- 自我反思问题和练习均在数据中与“书籍核心概念”分开记录；无法确认属于原书练习的内容标为夜喵新编或待核。

## 4. 对话上下文

`services/book-context.js` 会向 AI 注入：

1. 当前书籍与长简介；
2. 该书三个精选技能；
3. 当前技能的概念、场景、思考问题、练习、来源和核验状态；
4. 不虚构原书、不过度承诺、不诊断和安全求助边界。

对话存档使用 `bookId::skillId` 作用域。不同书或不同技能不会恢复彼此的临时对话现场；同一书籍的整书对话与单技能对话也相互隔离。

# 夜喵与记录页面实现

2026-10-11：依据 Figma 夜喵首页与记录页面实现，未修改 pages/breathe 文件。

- 夜喵底部导航：夜喵 / 呼吸 / 记录。记录打开独立 pages/record/index，呼吸沿用原页面。
- 记录月历默认当前月份；星期日开头，支持六行月份与前后月份切换。
- 周统计按周一至周日，计算真实本地记录的不同夜间日期。
- 上床时间分类：早睡 [21:00,23:00)，稍晚 [23:00,24:00) 与 [00:00,00:30)，晚睡 [00:30,05:00)。其他时段不算早睡。
- nightDate 是所属夜晚的完整日期。凌晨记录归前一晚。录入页选择的是夜间日期，保存时不重复减一天。
- 旧记录仅有月日，保留在睡眠记录历史，不猜年份，不填入月历。新记录按 nightDate 更新，保留最多 366 条。
- 感恩日记使用既有三条、每条 120 字流程；首页显示最近两篇，支持全部、全文和删除。
- 本地图片来自已有 Figma 交付素材；未引入网络图片或虚构统计。
- 夜喵 AI 对话保留现有连接预览状态，尚无真实 AI 服务。

检查：node --test tests/*.test.js；浏览器预览与 tools/verify-record.js。浏览器预览是 WXML 转换检查，最终需在微信开发者工具与真机检查原生 picker、胶囊和安全区。

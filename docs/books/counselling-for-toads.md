## 1. 书目身份卡

**作者**：罗伯特·戴博德（Robert de Board，1932—2020），英国心理咨询师与组织心理学者，剑桥大学赛尔文学院毕业，曾任教于英国亨利商学院；著有《咨询技巧》《组织的心理分析》。本书是他最畅销的大众心理学作品。

**体裁**：以《柳林风声》人物（蛤蟆、苍鹭、獾、河鼠、鼹鼠）写成的咨询故事——蛤蟆陷入抑郁，朋友督促他求助，苍鹭与他进行了十次面谈。全书按咨询进程展开，末章给出 TA 的框架总结。

**理论底座**：沟通分析（TA，Berne）——三种自我状态（PAC）、人生坐标、心理游戏、脚本（life script）。书中把抽象理论讲成对话，几乎可以当「咨询过程示范读本」。

--------------------------------------------------------------------

## 2. 三种自我状态（PAC）

**一句话**：人在任一时刻都处在三种状态之一——儿童自我、父母自我、成人自我；问题不是「有情绪」，而是被旧状态困住、成人不在场。

- **儿童自我状态（Child）**：行为与感受像孩子。「自然型儿童」——天生的情感（快乐、愤怒、悲伤、恐惧）；「适应型儿童」——为应对父母而发展出的策略（顺从、讨好、道歉、退缩）。被批评时瞬间「变小」，是适应型儿童的典型反应。
- **父母自我状态（Parent）**：把父母（或养育者）的言行内化，像「心里的长辈」那样说话——挑剔、训斥，或照顾、担忧。「挑剔型父母」最容易在自责时登场：「你怎么又这样。」
- **成人自我状态（Adult）**：用理性处理此时此地的现实——不评判、不委屈，能问「现在发生了什么，我有哪些选择」。**只有成人状态里能学到新东西**（书中苍鹭原话的要点）。

**夜喵用法**：不贴诊断标签，可以把状态当「翻译工具」——「听起来刚才那个声音很像心里的父母在说话」（描述状态，不评价人）。

--------------------------------------------------------------------

## 3. 人生坐标与自证预言

**一句话**：童年约四五岁时，每个人会回答两个问题——「我好吗？」「别人好吗？」——形成四种坐标，之后一生不断用行为去证明它（自证预言）。

1. **我好；你也好**——健康坐标：能接纳自己，也信任他人可合作。
2. **我好；你不好**——把问题归给他人，用指责维持「我是对的」。
3. **我不好；你好**——抑郁最常栖居的坐标：我差、别人强；容易讨好、自责、觉得拖累别人。
4. **我不好；你也不好**——虚无与绝望的坐标。

**自证预言机制**（书中用「酗酒」举例）：认为「生活不会善待我」→ 今晚喝醉 → 第二天果然难受 → 「看，果然如此」。重复的行为在印证旧的预期——这类长期重复就叫「心理游戏」。

**夜喵用法**：不直接给用户贴坐标（「你就是我不好你好」＝贴标签），而是描述**模式**：「好像每次聊到失误，你都会先把自己判一遍——像在验证某个早就写好的结论。」把「证明」变成「看见」，坐标才有可能移动。

--------------------------------------------------------------------

## 4. 情绪与「责怪」

- **情绪是信号，不是故障**：悲伤、愤怒、恐惧本身没有错——它们提示需要被照顾的部分（书中蛤蟆学会允许自己愤怒，而不是立刻压回去讨好）。
- **责怪属于儿童状态**：「责怪是人处在儿童自我状态里做的事情」（苍鹭语）。当人开始用成人状态问「我现在想要什么、能做什么」，责怪就失去场地。
- **诚实但不刻薄的翻译**：把「我怎么这么没用」翻译成「心里的挑剔父母又在说话了」——命名状态本身就能让成人回来一点。

--------------------------------------------------------------------

## 5. 夜喵对话适配（本产品最相关）

**可以做（对话层）**：
- 状态命名（温和、可选）：「听起来是心里那个挑剔的声音又来了」；
- 情绪正当化：「难过不用先证明自己值得难过」；
- 小小唤起成人状态：「此刻你能为自己做的一件小事是什么？」（关灯、喝水、把手机放远）；
- 模式看见：把「又失败了」翻译成「好像有个旧结论在等你去证明」；
- 与呼吸练习联动：把「回到此刻的身体」当作成人状态的身体入口。

**不可以做**：
- 不诊断（不说「你有抑郁/焦虑障碍」）、不替代咨询与治疗；
- 不把 TA 术语当武器（「你在玩心理游戏」会伤人）——只用生活化描述；
- 不劝用户「原谅父母」或做家庭评判；不替用户决定关系去留；
- 危机信号（自伤/轻生）优先走安全规则与求助卡。

## 6. 诚实边界（本卡自身的限度）

1. 本书是**通俗心理读物**，不是临床手册；TA 是心理教育框架，疗效证据有限，不构成治疗建议。
2. 书中人物与情节为叙事虚构（借《柳林风声》），不能当真实个案引用。
3. 本卡只直读中文译本；与 Berne 原著（《Games People Play》等）的对应关系未逐条核对。
4. 人生坐标是简化的四象限，真实的人会在坐标间移动，不要用坐标给人定型。

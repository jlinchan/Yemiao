# SleepWell 4-7-8 呼吸与身体扫描设计

首页和身体部位呼吸统一消费同一状态机。按住进入4秒深呼吸，持续按住自动进入7秒停留，停留结束后提示松手；松手随时开始8秒呼气。呼气完整结束才累计轮次，呼气期间重新按下会放弃当前轮次并立即开始新的吸气。

三个阶段使用小号倒计时和8%-12%的柔和视觉变化。吸气提示“感受腹部向外扩张”，停留提示“让这一口气停留片刻”，呼气提示“感受腹部慢慢回落”。吸气转停留、停留完成各轻震一次。

首页使用关闭图标退出小程序；身体选择和身体部位页使用返回箭头。导航位置来自真实状态栏和胶囊几何，不能侵入刘海区域。

身体选择使用用户提供的透明中性正面人体位图 `assets/body-silhouette-v2.png`，不显示五官、肌肉或医疗结构。默认热点不可见，选中后才出现局部柔光和名称；底部横向部位选择器与人体点击区域同步。主按钮未选择时禁用，随机选择只高亮不自动跳转。

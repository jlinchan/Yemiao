# Yemiao

夜喵微信小程序聚焦补丁分支：`codex/companion-book-skills-20261019`。

本 PR 只提交“陪伴者板块”和“书中技能板块”的最新实现、必要资源、知识文档及本 README，不包含其他页面、测试工具或整份小程序项目。

## 本次修改

### 1. 陪伴者板块

- 首页模块名称统一为“陪伴者”。
- 首页精选顺序固定为：
  1. 睡眠陪伴师
  2. 欧文·亚隆
  3. 共情陪伴师
- 完整陪伴者列表使用同一数据源和 `sortOrder`，顺序固定，不依赖接口返回顺序。
- 欧文·亚隆副标题为“心理大师同行疗愈”，首页只展示“跨时空对话”，完整列表展示“跨时空对话、深度共情”。
- 欧文·亚隆头像使用用户提供的图片，未重新生成。
- 首页睡眠陪伴师只展示“睡眠引导”一个标签，完整列表仍展示全部标签。
- 对话页顶部名称、消息发送者、开场语、输入提示和错误提示从当前 `counselorId` 动态读取。
- AI 系统提示同步使用当前陪伴者身份；欧文·亚隆视角明确标注为思想参考，不冒充本人。
- 不同陪伴者的对话存档按作用域隔离，避免互相恢复临时对话。

### 2. 书中技能板块

- 新增统一书籍目录 `data/book-directory.js`，包含稳定 `bookId`、排序、短简介、长简介、封面和标签。
- 《失眠的认知行为治疗》固定排在首页和完整列表第一位。
- 首页书籍简介使用 `shortDescription`，完整介绍使用 `introduction`。
- 新增动态书籍介绍页 `pages/book-detail/`，按 `bookId` 加载不同书籍。
- 首页和完整书籍列表点击封面进入对应书籍介绍页。
- 底部按钮统一为“开始对话”，直接进入当前书籍聊天，不再经过单本书筛选过渡页。
- 完整书籍列表保留，封面改为紧凑横向缩略图。
- 六本书各配置三项精选技能：
  - 失眠的认知行为治疗：记录睡眠日记、认识睡眠信念、建立睡眠联结
  - 被讨厌的勇气：区分课题、理解目的论、共同体感觉
  - 蛤蟆先生去看心理医生：认识自我状态、觉察情绪信号、看见旧模式
  - 自卑与超越：自卑与补偿、社会兴趣、人生三任务
  - 也许你该找个人聊聊：看见心理防御、重复的关系模式、表达脆弱
  - 非暴力沟通：观察与评论、感受与需要、清晰请求
- 技能点击传递 `bookId`、`skillId`，由 `services/book-context.js` 加载对应知识上下文。
- 增加重复点击保护，避免连续点击创建多个详情或聊天页面。

## 接入说明

`Yemiao/main` 当前只有 README 和 LICENSE，没有基础小程序代码。本分支按聚焦补丁方式提交，文件路径与夜喵现有工程保持一致。

合入完整工程时需确认：

1. `app.json` 已包含 `pages/book-detail/index`。
2. 首页、陪伴者页和聊天页依赖的通用组件、图标与底部导航已存在。
3. 若其他分支已修改 `app.json`，以合并方式追加 `pages/book-detail/index`，不要覆盖整份文件。
4. 本分支未携带测试文件和预览工具，避免影响其他贡献。

## 内容边界

- CBT-I、阿德勒相关书籍和《蛤蟆先生》使用仓库已有直读资料。
- 《也许你该找个人聊聊》和《非暴力沟通》标记为主题或核心框架已核，原文页码与逐字练习仍待核。
- 不诊断、不替代专业心理咨询；CBT-I 睡眠限制不向普通用户提供自行调整处方的能力。
